# 婚纱摄影分类优化方案

## 定位理由

现有`婚礼摄影`同时承担了婚纱照、婚礼现场和婚礼肖像，导致婚前外景婚照会被错误归入婚礼当天纪实。新增`婚纱摄影`后，分类依据从“都与结婚有关”改为“拍摄服务/成片的叙事时点与内容重点”，可以区分婚前婚纱照和婚礼现场记录。

## 分类树

```text
图像分类
└─ 摄影
   └─ 人像摄影
      ├─ 肖像摄影：面部、身份和气质是主体
      ├─ 生活方式摄影：日常、家庭、情侣与品牌生活场景
      ├─ 婚纱摄影（新增）：婚前/婚纱照拍摄与成片
      │  ├─ 室内婚纱拍摄
      │  ├─ 外景婚纱拍摄
      │  ├─ 礼服造型与租赁线索
      │  └─ 选片、修片、相册成片线索
      ├─ 婚礼摄影：婚礼仪式、婚宴、接亲及婚礼当天纪实
      ├─ 儿童摄影：儿童、新生儿与家庭纪念
      └─ 人物艺术摄影：人体、舞蹈、运动等肢体艺术表达
```

`礼服造型`、`婚纱造型`和`新娘写真`仍属于现有的服饰/人物维度，可作为关联分类；它们不是`婚纱摄影`的同级替代项。

## 类目定义与示例

| 类目 | 层级 | 边界 | 典型示例 |
| --- | --- | --- | --- |
| 人像摄影 | 一级分组 | 人物影像内容的入口，不直接作为叶子分类 | 人像类素材导航 |
| 婚纱摄影 | 二级叶子 | 婚前拍摄、婚纱照服务或婚纱成片；可有室内/外景、礼服租赁、造型、修片和相册交付 | 花海婚纱照；影棚婚纱相册样片 |
| 婚礼摄影 | 二级叶子 | 婚礼当天事件记录，必须有仪式、婚宴、接亲或现场纪实证据 | 婚礼仪式抓拍；婚宴现场记录 |
| 肖像摄影 | 二级叶子 | 面部、身份和气质本身是主体，不因穿婚纱自动触发 | 新娘面部肖像；职业肖像 |
| 生活方式摄影 | 二级叶子 | 情侣或家庭与生活环境的互动是主体，且没有婚纱照/婚礼事件的直接证据 | 情侣居家生活；婚后生活方式品牌片 |
| 人物艺术摄影 | 二级叶子 | 肢体、舞蹈或人体艺术表达是主体 | 婚纱舞蹈创作；舞台肢体艺术 |

## 互斥与优先级

1. 有婚礼仪式、婚宴、接亲或婚礼现场证据：优先`婚礼摄影`。
2. 只有婚纱照、婚前外景、婚纱相册、礼服租赁/造型/修片交付等婚前服务或成片证据：归`婚纱摄影`。
3. 同时出现婚前与婚礼当天两套内容时，允许保留两个叶子；单一画面不能仅因“婚纱”“新娘”同时命中两个类目。
4. 只有婚纱服装细节、没有人物影像叙事时，优先`时尚摄影`或`产品摄影`，并关联`婚纱造型`，不强行归婚纱摄影。
5. 只有新娘面部特写、没有婚纱照服务或婚前成片语境时，可归`肖像摄影`，并关联`新娘写真`。
6. “婚礼服务”“摄影摄像”是服务行业通称，不新增为图像内容分类；它们不能覆盖具体的婚纱摄影/婚礼摄影叶子。服务形式、价格和风格作为标签或业务字段维护。

## 服务、价格与风格的落地规则

- 服务形式：室内棚拍、外景旅拍、礼服租赁、化妆造型、选片修片、相册交付等，作为事实标签/服务字段，不拆成多个摄影类目。
- 价格区间：低价/中价/高价或具体套餐价格不是稳定图像分类，进入业务字段或可更新标签，避免价格变化导致分类迁移。
- 风格特点：纪实、电影感、森系、国风、极简等进入现有风格维度或标签；不能生成“高级感婚纱摄影”一类伪分类。

## 实现结果

- 系统在人像摄影分组新增稳定叶子`婚纱摄影`，旧`婚纱摄影`别名不再映射到`婚礼摄影`。
- 本地文本匹配将“婚纱照/婚纱写真/婚前照”提升为婚纱摄影，将“婚礼仪式/婚宴/接亲”保留为婚礼摄影。
- 远程图像/提示词分类均接收同一套边界，明确禁止把“婚礼服务”“摄影摄像”当作图像分类。
- 现有标签、场景、服饰和风格维度保持不变，避免新增分类与原有正交维度重叠。
