# 按钮文本长度规范

> 适用于 `W:\提示词` 工作区内所有按钮类组件（`Button`、`IconTooltipButton`、`ConfirmDialog`、`ConfirmBubble` 及业务页面中的原生 `<button>`）。本规范为后续开发与 UI 走查提供统一参考，避免因按钮文本过长导致的布局错位、溢出或截断后无法查看完整内容的问题。

## 1. 文本长度分级

| 级别 | 中文长度 | 英文长度 | 典型场景 | 处理方式 |
| --- | --- | --- | --- | --- |
| 短文本 | ≤ 4 字 | ≤ 10 字符 | 取消、确定、完成、添加图片 | 直接显示，无需特殊处理 |
| 中等文本 | 5–8 字 | 11–16 字符 | 批量删除所选项目、压缩并替换原图 | 直接显示，受默认 `max-width: 16rem` 约束 |
| 长文本 | 9–14 字 | 17–28 字符 | 包含动态数量/文件名的按钮、复合动作描述 | 截断 + 原生 `title` tooltip 显示完整文本 |
| 超长文本 | > 14 字 | > 28 字符 | 不推荐用于按钮 | 拆分为标题 + 说明文案，按钮仅保留动词 |

**硬性上限**：按钮可见文本不得超过 14 个中文字符。超出时应优先拆分信息架构，而非依赖截断。

## 2. 组件能力约定

### 2.1 `Button`（`src/components/ui/Button.tsx`）

- 默认 `maxWidth = "16rem"`，按钮自身始终带 `max-w-full`，不会溢出父容器。
- 默认单行截断（`min-w-0 truncate`），当文本超出 `maxWidth` 时显示省略号。
- 当 `children` 为字符串时，自动注入原生 `title` 属性，截断后鼠标悬停可查看完整文本。
- 需要多行折行时传入 `multiline`，文本将以 `whitespace-normal break-words text-center leading-tight` 显示，适用于固定窄容器内的动作按钮。
- 需要移除宽度上限（如纯图标按钮通过 `className="size-10 px-0"` 固定尺寸）时传入 `maxWidth={false}`。

### 2.2 `IconTooltipButton`（`src/components/ui/IconTooltipButton.tsx`）

- 按钮内仅显示图标，`label` 通过 portal tooltip 完整展示。
- tooltip bubble 由 `tokens.css` 中 `.icon-tooltip-button__bubble` 控制：`max-width: min(12rem, calc(100vw - 2rem))`，`white-space: normal` + `word-break: break-word`，长 label 自动折行。
- 窄屏（`max-width: 1000px`）下 tooltip 放宽至 `min(220px, 70vw)`。

### 2.3 `ConfirmBubble`（`src/components/ui/ConfirmBubble.tsx`）

- 固定容器 `w-72`（288px），动作区为 2 列 grid。
- 动作按钮使用折行模式（`min-w-0 break-words text-center leading-tight`），保证动作动词始终完整可见，不截断。
- 同时注入 `title` 作为兜底 tooltip。

### 2.4 `ConfirmDialog` / `AppDialog` footer

- footer 使用 `flex flex-wrap justify-end gap-2`，按钮超长时自动换行至下一行而非挤压同行按钮。
- 按钮复用 `Button` 的默认 `maxWidth`，避免单个按钮独占整行。

## 3. 容器布局规范

1. 按钮行容器应使用 `flex` + `flex-wrap`，禁止对按钮设置固定像素 `width`。
2. 按钮在 grid 容器中作为子项时，必须添加 `min-w-0` 以允许收缩。
3. 禁止对按钮文本使用 `white-space: nowrap`（tooltip bubble 除外，且必须配合 `max-width` + 折行回退）。
4. 同一行多个按钮应保持相同高度（`min-h-10` 或 `min-h-9`），避免因文本折行导致高度错位。

## 4. 响应式适配

- 按钮内边距统一使用 `px-3 py-2`（标准）或 `px-3 py-1.5`（紧凑，用于 bubble）。
- 窄屏下通过 `flex-wrap` 自然换行，不单独缩小按钮尺寸。
- tooltip 在窄屏自动放宽 `max-width`，避免被视口裁剪。

## 5. 走查清单

新增或修改按钮时，按以下清单自检：

- [ ] 可见文本是否在 14 个中文字符以内？
- [ ] 按钮是否在 `flex` 容器中且未设置固定宽度？
- [ ] 长文本是否截断并附带 `title` 或 tooltip？
- [ ] 固定窄容器内的动作按钮是否启用折行而非截断？
- [ ] 同行按钮高度是否一致？
- [ ] 窄屏（< 1000px）下按钮行是否正常换行、tooltip 是否被裁剪？

## 6. 回归测试

`tests/unit/buttonTextStyle.test.ts` 通过静态分析锁定以下关键约束，防止后续修改回退：

- `Button` 含 `max-w-full`、`min-w-0 truncate`、默认 `maxWidth = "16rem"`、`resolvedTitle` 注入。
- `Button` 支持 `multiline` 折行模式。
- `ConfirmBubble` 动作按钮含 `min-w-0`、`break-words`、`text-center`。
- `.icon-tooltip-button__bubble` 使用 `white-space: normal` + `word-break: break-word`，不再使用 `nowrap`。
