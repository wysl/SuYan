# 胶囊样式规范

> 适用于 `W:\提示词` 工作区内所有"胶囊"形态组件：提示词参数胶囊、标签/分类徽标、加载占位 chip、排序环菜单色块、推荐卡片配色等。本规范统一胶囊的视觉契约、交互行为与使用边界，使其与 [按钮文本长度规范](./按钮文本长度规范.md) 中的按钮组件保持同等标准化水平。
>
> 单一来源：`src/components/ui/capsuleTones.ts`（`CAPSULE_TONES`）+ `src/components/ui/Capsule.tsx`（规范组件）。新增胶囊色或形态时必须先在此处与 `src/styles/tokens.css` 同步追加，再在业务侧消费。

## 1. 组件分类

项目内"胶囊"分为两类，共享同一套配色 token，但形态与交互不同：

| 类型 | 形状 | 尺寸 | 阴影 | 交互 | 典型场景 | 规范组件 |
| --- | --- | --- | --- | --- | --- | --- |
| **真胶囊（Capsule）** | `rounded-full`（药丸形） | sm | `shadow-elevated` | 可点击（button）/静态（span） | 提示词参数胶囊、加载占位 chip | `<Capsule shape="pill">` |
| **圆角徽标（Badge）** | `rounded-md` | md | 无 | 静态为主 | 标签、分类、数量标记 | `<Capsule shape="rounded">` |

> 历史代码中存在 `rounded-lg`/`rounded-xl` 等圆角变体用于胶囊色块（如排序环图标容器、推荐卡 icon），属卡片级容器，不属于胶囊文本组件范畴，不在本规范强制收敛范围，但配色必须取自 `CAPSULE_TONES`。

## 2. 尺寸规格

| 尺寸 | 内边距 | 字号 | 行高 | 字重 | 最小高度 | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| `sm`（默认） | `px-2 py-0.5` | `text-[11px]` | `leading-5`（20px） | `font-semibold` | 自然高度 | 真胶囊：提示词参数、行内 chip |
| `md` | `px-2 py-1` | `text-xs`（12px） | 自然（不强制） | 继承（400–600） | 自然高度 | 圆角徽标：标签、分类、数量 |

- 字体族：`font-sans`（真胶囊强制；徽标继承容器）。
- 真胶囊行高固定 20px，保证多色胶囊在提示词段落中基线对齐。
- 徽标不强制行高，以适配 `flex items-center` 容器自然居中。

## 3. 形状与圆角

| 形状 | 圆角类 | CSS 等效 | 适用 |
| --- | --- | --- | --- |
| `pill` | `rounded-full` | `border-radius: 9999px` | 真胶囊 |
| `rounded` | `rounded-md` | `border-radius: 0.375rem`（6px） | 圆角徽标 |

- 禁止对胶囊文本组件使用 `rounded-lg`/`rounded-xl`/`rounded-2xl`（这些保留给卡片级容器）。
- 加载占位 chip（`.app-loading-prompt-chip`）使用 `border-radius: 999px`，等价 pill，归入真胶囊。

## 4. 颜色系统

### 4.1 Tone 枚举（9 个）

8 个胶囊色 + 1 个强调色，每个 tone 在 `tokens.css` 中定义 3 个变量（背景/前景/边框），并覆盖 light / dark / auto 三套主题：

| Tone | 语义 | 典型参数维度 |
| --- | --- | --- |
| `sage` | 鼠尾草绿 | 服装、图像风格、导入时间 |
| `mist` | 雾蓝 | 动作、景别、字体、修改时间、尺寸 |
| `clay` | 陶土 | 宽高比、手势、文本内容 |
| `lavender` | 薰衣草 | 镜头角度、名人、手持道具、随机 |
| `fog` | 雾灰 | 景深、光影、未分类 |
| `rose` | 玫瑰 | 颜色、颜色细节、面部妆容 |
| `sand` | 沙黄 | 氛围、发饰 |
| `stone` | 石灰 | 回避、品牌、构图、细节、受光（默认兜底） |
| `primary` | 主色强调 | 当前值、选中态、推荐卡强调 |

> `primary` 不是胶囊色，用于"当前/强调"语义，色值取自 `--color-primary` / `--color-primary-soft`。

### 4.2 Variant（状态映射）

每个 tone 在 `CAPSULE_TONES` 中提供以下字面量类名集合：

| Variant | 构成 | 用途 |
| --- | --- | --- |
| `solid` | 边框 + 背景 + 文本 | 默认展示态（静态/默认） |
| `outline` | 边框 + 文本（无背景） | 静态描边胶囊 |
| `buttonOutline` | 边框 + 文本 + `hover:bg-{tone}` | 可点击描边胶囊（悬停填充） |
| `selected` | 边框 + `linear-gradient({tone}→panel)` + `shadow-elevated` + `text-foreground` | 可替换词条菜单选中态 |
| `borderHover` | 边框 + `hover:` 同色边框 | 推荐卡片 article 描边 |
| `iconTone` | 边框 + `bg-panel/80` + 文本色 | 推荐卡片 icon 容器 |
| `indicatorBg` | `[&>span:first-child]:bg-{tone}-foreground` | 前导圆点指示符 |

### 4.3 交互状态

| 状态 | 真胶囊（`as="button"`） | 圆角徽标（`as="span"`） |
| --- | --- | --- |
| **正常** | `solid` + `shadow-elevated` | `solid`，无阴影 |
| **悬停** | `hover:bg-panel`（中性抬起，覆盖 tone 背景） | 无（静态） |
| **聚焦** | `focus-visible:ring-2 focus-visible:ring-primary/30` | 无 |
| **激活/选中** | `selected`（渐变 + 阴影） | 不适用 |
| **禁用** | `disabled:cursor-not-allowed disabled:opacity-60` | 不适用 |

- 真胶囊悬停使用中性 `bg-panel` 而非 tone 色，避免色相跳变，与提示词正文背景融合。
- 描边胶囊（`variant="outline"` + `as="button"`）悬停填充 tone 背景（`buttonOutline`），用于推荐卡按钮等需要强调色反馈的场景。
- 禁用态统一 `opacity-60` + 禁用光标，不改变 tone。

## 5. 文本与截断

- 真胶囊默认 `maxWidth="14rem"`，超出截断（`min-w-0 truncate`）并自动注入原生 `title` 显示完整文本（当 children 为字符串时）。
- 圆角徽标同样默认 `maxWidth="14rem"`，长标签/分类名截断 + tooltip。
- 需要完整展示（如数量标记 `+N`）时传 `maxWidth={false}` 关闭截断。
- 胶囊文本硬上限：12 个中文字符（真胶囊）/ 8 个中文字符（徽标）。超出应拆分信息架构，而非依赖截断。

## 6. 阴影

| 场景 | 阴影类 |
| --- | --- |
| 真胶囊（button，solid/selected） | `shadow-elevated` |
| 真胶囊（span，静态 solid） | 无 |
| 圆角徽标 | 无 |
| 选中态（selected） | `shadow-elevated`（来自 tone.selected） |

## 7. 交互反馈机制

1. **可点击胶囊**：`as="button"`，具备 `hover:bg-panel` + `focus-visible:ring` + `disabled` 反馈，`type="button"`，必须提供 `aria-label` 或可读文本。
2. **静态胶囊**：`as="span"`（默认），无交互反馈，用于纯展示。
3. **键盘可达**：可点击胶囊必须可通过 Tab 聚焦，Enter/Space 触发，聚焦环可见。
4. **前导圆点**：`indicator` prop 渲染 `<span aria-hidden>`，背景取 `indicatorBg`，用于"当前值"等状态指示。
5. **双击防冒泡**：在提示词正文中嵌入的可点击胶囊需 `onDoubleClick` 阻止冒泡，避免触发父级编辑（参考 `PromptDetailDialog` 既有实现）。

## 8. 适用场景与使用限制

### 应当使用
- 提示词参数胶囊（真胶囊，pill，sm，可点击）
- 标签 / 分类 / 数量标记（圆角徽标，rounded，md，静态）
- 加载占位 chip（真胶囊，pill，自定义 min-height 28px，使用 `.app-loading-prompt-chip`）
- 可替换词条菜单选项（真胶囊，pill，sm，solid/selected 切换）
- 排序环菜单色块（卡片级容器，配色取 `CAPSULE_TONES[tone].solid`）
- 推荐卡片配色体系（article/button/header/icon/tag 五字段，派生自 `CAPSULE_TONES`）

### 禁止使用
- 用胶囊承载超过 12 个中文字符的长文本（改用卡片或段落）。
- 用胶囊替代主操作按钮（主操作必须用 `Button` 组件）。
- 在胶囊上手写 `border-capsule-*`/`bg-capsule-*`/`text-capsule-*` 三元组（必须取自 `CAPSULE_TONES`）。
- 动态拼接胶囊类名（如 `` `bg-capsule-${tone}` ``）—— Tailwind JIT 无法解析，必须使用 `CAPSULE_TONES` 中的字面量。
- 在胶囊内放置块级元素或换行符（胶囊为单行 inline-flex）。

## 9. 响应式与多设备

- 胶囊在 `flex flex-wrap` 容器中自然换行，不单独缩小尺寸。
- `max-w-full` 确保胶囊不溢出父容器；窄屏下长文本截断 + tooltip 兜底。
- 暗色主题（`data-theme="dark"` 与 `prefers-color-scheme: dark`）下，所有 tone 自动切换为深色变体，无需额外适配。
- 窄屏（< 1000px）下胶囊内边距与字号保持不变，依靠 `flex-wrap` 与截断保证布局稳定。
- 高 DPI 屏幕下 `shadow-elevated` 仍清晰可见，无需调整。

## 10. 视觉验收标准

新增或修改胶囊时，按以下清单验收：

- [ ] 配色取自 `CAPSULE_TONES`，未手写 `capsule-*` 三元组？
- [ ] 形状正确：真胶囊 `rounded-full`，徽标 `rounded-md`？
- [ ] 尺寸正确：真胶囊 sm（`text-[11px]`/`leading-5`/`font-semibold`），徽标 md（`text-xs`）？
- [ ] 可点击胶囊具备 hover（`bg-panel` 或 `buttonOutline`）/ focus-ring / disabled 反馈？
- [ ] 静态胶囊无 hover/阴影？
- [ ] 长文本截断并附带 `title` tooltip？
- [ ] 暗色主题下所有 tone 可读、对比度达标？
- [ ] 真胶囊在提示词段落中基线对齐（`translate-y-[1px]` 由调用方按需追加）？
- [ ] 同行多色胶囊高度一致？
- [ ] 窄屏下不溢出、不撑破容器？

## 11. 实施指引

### 11.1 单一来源

```
src/components/ui/capsuleTones.ts   # CAPSULE_TONES（tone → 类名集合）
src/components/ui/Capsule.tsx       # 规范组件
src/styles/tokens.css               # --color-capsule-* 变量（light/dark/auto）
```

新增胶囊色流程：
1. 在 `tokens.css` 的 4 处主题块（root / `[data-theme="light"]` / `@media (prefers-color-scheme: dark)` / `[data-theme="dark"]`）追加 `--color-capsule-{t}` / `-foreground` / `-border`。
2. 在 `capsuleTones.ts` 的 `CapsuleTone` 联合类型与 `CAPSULE_TONES` 记录中追加该 tone 的全部 variant 字面量。
3. 在本规范 §4.1 表格登记语义。

### 11.2 消费方式

```tsx
// 真胶囊（可点击参数胶囊）
<Capsule as="button" tone="sage" shape="pill" size="sm" onClick={...}>
  {value}
</Capsule>

// 圆角徽标（静态标签）
<Capsule tone="mist" shape="rounded" size="md">{tag}</Capsule>

// 选中态
<Capsule as="button" tone="lavender" variant="selected" indicator>{option}</Capsule>

// 仅取配色类名（用于卡片级容器）
const colorClassName = CAPSULE_TONES.sage.solid;
```
