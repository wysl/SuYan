# 饮品摄影分类体系

## 1. 体系定位

`饮品摄影`是分类树中的一级分组，下面的六个叶子分类才是可分配、可检索的二级分类。它与`商业摄影`、`平面设计`等分组并列；饮品广告的商业属性、海报版式和光线属性不能替代饮品主体分类。

分类只回答“这张图主要拍的是什么、处于什么饮品场景”，不承担颜色、景深、光线和情绪分析。上述属性继续由标签或其他属性分析处理。

## 2. 完整分类表

| 分类名称 | 层级 | 分类描述 | 适用范围 | 典型示例 |
| --- | --- | --- | --- | --- |
| 饮品摄影 | 一级分组 | 饮品主题摄影的检索入口，不直接作为素材叶子分类 | 咖啡、茶饮、酒类、软饮及饮品制作和场景化画面 | 饮品类作品导航 |
| 咖啡摄影 | 二级叶子 | 咖啡是画面核心主体 | 咖啡、浓缩、拿铁、美式、手冲、冷萃等 | 手冲咖啡静物、冰拿铁广告 |
| 茶饮摄影 | 二级叶子 | 茶类或茶基底饮品是画面核心主体 | 茶、奶茶、抹茶、果茶、红茶、绿茶、乌龙茶等 | 抹茶奶茶商业海报、茶杯与茶汤 |
| 酒精饮品摄影 | 二级叶子 | 酒精饮品是画面核心主体 | 葡萄酒、香槟、啤酒、鸡尾酒、威士忌、白酒及烈酒 | 鸡尾酒广告、葡萄酒瓶与酒杯 |
| 非酒精饮品摄影 | 二级叶子 | 非酒精饮品是画面核心主体，且不属于咖啡或茶饮 | 果汁、汽水、碳酸饮料、乳饮料、矿泉水、能量饮料、冰沙等 | 橙汁产品图、汽水广告 |
| 饮品制作过程摄影 | 二级叶子 | 制作动作或步骤是画面叙事重点 | 冲泡、萃取、调酒、倒液、打奶泡、搅拌、装杯、封口等 | 手冲注水、调酒倒液、奶泡制作 |
| 饮品与场景结合摄影 | 二级叶子 | 饮品与环境、生活方式或使用情境形成明确关系 | 咖啡馆、酒吧、餐桌、厨房、户外和生活方式场景；类型不明确时兜底 | 户外餐桌上的饮品、酒吧环境中的酒杯 |

## 3. 分类原则

1. 主体优先：以画面视觉重点或提示词明确描述的主体为准，不因“广告”“品牌”“海报”改变主体。
2. 证据优先：只能使用画面或正向提示词中的直接证据；无法确认饮品类型时不猜具体类型。
3. 叶子可分配：`饮品摄影`只作为一级导航分组，分析结果必须落到六个二级叶子之一。
4. 正交属性分离：自然光、棚拍光、柔光、色调、景深、浪漫感等不是饮品分类，不应出现在分类胶囊中。
5. 泛类降级：明确饮品主体时，不再用`食品摄影`或`产品摄影`作为替代分类。只有画面同时存在独立的非饮品食品主体时，才允许保留`食品摄影`作为第二内容类型。

## 4. 优先级规则

分析时按以下顺序判定：

1. 制作过程优先：制作动作是主体时，先选`饮品制作过程摄影`；若饮品类型明确，可同时关联对应类型叶子。
2. 明确类型其次：咖啡→`咖啡摄影`；茶、奶茶、抹茶、果茶→`茶饮摄影`；酒类→`酒精饮品摄影`；其他非酒精饮料→`非酒精饮品摄影`。
3. 场景兜底：类型无法确认，但饮品与咖啡馆、酒吧、餐桌、厨房、户外等环境关系明显，选`饮品与场景结合摄影`。
4. 形式不抢主体：商业广告、品牌宣传、海报版式、包装展示、商业布光只作为用途、设计或属性依据，不能覆盖饮品叶子。
5. 关联数量控制：同一饮品分组最多保留主类型和一个有直接证据的邻接叶子，避免六个饮品分类同时出现。

## 5. 关联分类推荐

关联分类只在画面有直接证据时推荐：

| 主分类 | 可关联分类 | 触发条件 |
| --- | --- | --- |
| 咖啡摄影 / 茶饮摄影 / 酒精饮品摄影 / 非酒精饮品摄影 | 饮品与场景结合摄影 | 场景对使用情境有明显叙事作用 |
| 任一明确饮品类型 | 饮品制作过程摄影 | 制作动作是画面重点或清晰可见 |
| 任一饮品叶子 | 商业广告 | 有明确卖点、促销或行动号召 |
| 任一饮品叶子 | 海报设计 | 画面本质是平面设计稿，并同时具备主标题、文案块、品牌标识和版权/联系信息 |
| 饮品包装/礼盒为核心 | 产品摄影 | 包装外观本身是视觉主体；饮品内容仍可作为主题关联 |

不推荐仅凭以下证据建立关联：颜色、季节、柔光/棚拍光、浅景深、浪漫唯美、单个 Logo、水印或普通广告用途。

## 6. 边缘案例

- 奶茶广告：主分类为`茶饮摄影`；若环境构成叙事，再关联`饮品与场景结合摄影`；不因广告排版自动归入`产品摄影`或`海报设计`。
- 咖啡制作教程：主分类为`饮品制作过程摄影`，可关联`咖啡摄影`。
- 无法辨认的透明液体：不猜“果汁”或“酒”，使用`饮品与场景结合摄影`的前提是场景关系确实明确，否则不分配饮品叶子。
- 酒瓶礼盒静物：若核心是包装结构和礼盒外观，使用`产品摄影`；若酒液、酒杯和饮用场景是主体，使用`酒精饮品摄影`。
- 饮品与蛋糕同框：若饮品占主导，使用对应饮品叶子；若蛋糕和饮品共同构成餐饮主体，可同时保留`食品摄影`，但不得让泛类替代饮品叶子。

## 7. 实现约束

- 系统分类稳定 ID 由`饮品摄影`分组和六个叶子名称生成，新增版本不会改变既有分类 ID。
- 旧的`咖啡摄影→食品摄影`映射已取消；咖啡、奶茶、酒类、果汁和制作动作均有明确别名映射。
- 本地文本匹配对明确饮品信号提升饮品叶子权重，并压低旧的食品/产品泛类。
- 远程分类提示词要求模型只返回二级叶子，并执行“制作过程→明确类型→场景结合”的优先级。
- 自动化测试覆盖别名解析、系统分类树、文本匹配、饮品广告和制作过程优先级。
